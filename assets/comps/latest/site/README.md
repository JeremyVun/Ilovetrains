# App website calibration

Selected screenshot-led design, verified 9 September 2026 against `site/`.
These are real Chromium captures at 390×844 and 1440×900 CSS pixels in both
system colour schemes. Desktop landing captures include the feature sections
and actual document bottom. Phone captures use a 2× device scale.

The embedded app screens are lossless copies of the iOS calibration baselines,
with seeded example journeys. The website must preserve their aspect ratio.

Additional browser checks covered 320, 412 and 900 pixel widths, document
scrolling, keyboard focus, image loading, contrast and footer reachability.
Replace these frames when the accepted website design changes.
